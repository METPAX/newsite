# ТОО «Колор» — Интернет-магазин мебельного цеха

## Технологии
- **PHP 8.0+** — серверная часть
- **MySQL 5.7+ / MariaDB 10.3+** — база данных (управление через phpMyAdmin)
- **HTML5 + CSS3** — вёрстка без CSS-фреймворков
- **Vanilla JS** — минимальный JavaScript

---

## Установка

### 1. Требования
| Компонент | Версия |
|-----------|--------|
| PHP | 8.0 или выше |
| MySQL / MariaDB | 5.7 / 10.3 и выше |
| phpMyAdmin | любая актуальная |
| Apache / Nginx | с поддержкой PHP |

Расширения PHP: `pdo`, `pdo_mysql`, `mbstring`

---

### 2. Создание базы данных через phpMyAdmin

1. Откройте **phpMyAdmin** (обычно `http://localhost/phpmyadmin`)
2. В левой панели нажмите **«Новая»**
3. Введите имя базы: `kolor_shop`
4. Выберите кодировку: `utf8mb4_unicode_ci`
5. Нажмите **«Создать»**
6. Перейдите на вкладку **«Импорт»**
7. Нажмите **«Выберите файл»** и загрузите `kolor_shop.sql`
8. Нажмите **«Вперёд»** — таблицы и данные создадутся автоматически

---

### 3. Настройка подключения

Откройте файл `includes/db.php` и укажите ваши параметры MySQL:

```php
define('DB_HOST', 'localhost');   // Хост MySQL
define('DB_NAME', 'kolor_shop'); // Имя базы данных
define('DB_USER', 'root');        // Пользователь MySQL
define('DB_PASS', '');            // Пароль MySQL
```

---

### 4. Размещение файлов

Скопируйте папку `kolor-shop` в корень веб-сервера:
- **XAMPP:** `C:\xampp\htdocs\kolor-shop\`
- **Denver:** `C:\WebServers\home\localhost\www\kolor-shop\`
- **OpenServer:** `C:\OpenServer\domains\kolor.local\`
- **Linux/Mac:** `/var/www/html/kolor-shop/`

Сайт будет доступен по адресу: `http://localhost/kolor-shop/`

---

### 5. Данные для входа в админ-панель

> Данные закомментированы в `includes/db.php` в функции `seedData()` и в `kolor_shop.sql`

| Поле | Значение |
|------|----------|
| Email | `admin@kolor.kz` |
| Пароль | `admin123` |

**Для смены пароля** выполните в командной строке:
```bash
php -r "echo password_hash('НовыйПароль', PASSWORD_DEFAULT);"
```
Полученный хэш вставьте в таблицу `users` через phpMyAdmin.

├── profile.php          # Личный кабинет

│   ├── index.php        # Дашборд (статистика)

## Структура базы данных

| Таблица | Описание |
|---------|----------|
| `users` | Зарегистрированные покупатели и администраторы |
| `categories` | Категории мебели |
| `products` | Товары с ценами и характеристиками |
| `cart` | Корзина каждого покупателя |
| `orders` | Оформленные заказы |
| `order_items` | Состав каждого заказа |

---

## Функциональность

### Покупатели
- Регистрация и авторизация
- Каталог с фильтрацией по категориям и поиском
- Подробная страница товара
- Добавление в корзину, управление количеством
- Оформление заказа с адресом доставки
- Личный кабинет: история заказов, редактирование профиля

### Администратор (`/admin/`)
- Дашборд: кол-во заказов, товаров, клиентов, выручка
- Управление товарами: добавление, редактирование, удаление, переключение хита/наличия
- Управление заказами: список, детали, смена статуса
- Список клиентов с суммой покупок

---

## Добавление фотографий товаров

Поместите изображения в папку `assets/img/products/` и укажите имя файла (например `sofa1.jpg`) в поле **«Файл изображения»** при редактировании товара в админ-панели.
